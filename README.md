## 🎮 游戏简介

你是一名空降的组织变革顾问。恒信集团——一家成立三十年的传统公司——正深陷组织熵增：部门墙高筑、流程僵化、会议成灾、AI 工具被禁。董事会给了你唯一的权限：**注入新的人才**。

- **4 位可玩角色**（AI 原生人才原型）：苏澄「首席判断官」、林问「提问教练」、温故「品味鉴赏家」、骆执行「Agent 指挥官」
- **4 幕爬塔**：从 0 到 1 → 规模化 → 人机协同治理 → 终章·终极重构
- **4 个 BOSS**：部门墙·科层巨像 / 层级巨兽·大公司病 / 克朗娜危机·全自动客服巨脑 / 组织熵增之王（两阶段）
- **54 张卡牌**：执行/协作/制度/战略四类，【提问】【判断】【鉴赏】【编排】等关键词构成跨角色协同套路
- **23 件组织遗物**：每件都映射真实管理案例（Anthropic 两周一讲、出门问问 CodeBanana、微软 human-agent ratio、Klarna 教训……）
- **8 个管理两难事件**：裁员还是培训？坚持自动化还是召回人类客服？

## 🚀 快速开始

### 运行方式
直接用浏览器打开 `index.html` 即可（无需服务器、零依赖、完全离线）。

推荐 Chrome / Edge，窗口 ≥ 1280×800。

### 操作指南
- **点击卡牌**打出（消耗 Token）
- **多敌人时**先点卡再点目标
- **敌人头顶**公示下回合意图——预判取舍是核心策略
- **「结束回合」**后敌人行动，防火墙（格挡）清零
- **地图上**点击发光节点选择路线

## 🎯 核心机制

| 机制 | 说明 |
|------|------|
| **Token** | 每回合 3 点能量，用于打出卡牌（人才行动） |
| **防火墙** | 格挡值，回合结束清零——护得住一时，护不住一世 |
| **意向公告** | 敌人会公示下回合行动，明牌博弈是核心策略 |
| **关键词协同** | 【提问】【判断】【鉴赏】【编排】组合使用有乘法效应 |
| **删牌哲学** | 卡组不是越多越好——"优化编制"往往比加牌更强 |

## 🏆 四位变革领袖

| 角色 | 定位 | 核心资源 | 被动技能 |
|------|------|----------|----------|
| 苏澄 | 首席判断官 | 判断点（上限3） | 每回合未打判断牌获得1判断点 |
| 林问 | 提问教练 | 问题数（无上限） | 每打出1张提问牌抽1张 |
| 温故 | 品味鉴赏家 | 打磨值 | 战斗开始揭示所有敌人意图 |
| 骆执行 | Agent 指挥官 | Agent计数 | 第3张起出牌费用-1 |

## 👹 Boss 战设计

| Boss | 机制 | 应对策略 |
|------|------|----------|
| **部门墙·科层巨像** | 蓄力→爆发、受伤召唤守卫 | 打断蓄力阶段，控制召唤节奏 |
| **层级巨兽·大公司病** | 层级无限叠加（上限5层） | 50%血量前解决战斗，避免雪球 |
| **克朗娜危机·全自动客服巨脑** | 客户不满累积→舆情爆发 | 用提问/共情类卡牌削减不满 |
| **组织熵增之王** | 4形态×2回合循环 | 针对形态弱点出牌：提问克怀疑、鉴赏克惯性 |

## 🛠️ 技术架构

```
js/engine.js  战斗引擎（纯逻辑，无 DOM 依赖，可 headless 模拟）
js/data.js    全部内容数据（卡牌/敌人/遗物/事件/剧情，数据驱动）
js/map.js     StS 式分层地图生成
js/audio.js   WebAudio 程序化音效（无音频文件）
js/ui.js      UI 控制器与游戏流程
css/style.css 视觉样式
assets/       35 张 AI 生成美术（角色立绘/BOSS/敌人/背景）
tests/sim.js  数值平衡模拟（node tests/sim.js）
tests/e2e.js  端到端全流程自动测试（?test=1）
```

## 📚 设计依据

游戏内容改编自真实商业案例：
- Anthropic 组织结构（两周一讲文化）
- 出门问问"超级组织"（CodeBanana 平台）
- 微软 2025 Work Trend Index（Frontier Firm）
- Klarna 纯 AI 客服反转（裁员增效教训）
- 英伟达扁平化（直达老板的邮箱）

卡牌数值遵循《杀戮尖塔》拆解基准（1 Token ≈ 6 点伤害价值）。
